## Plano congelado — fluxo de teste do QA-Agent

### Problema (do agente, não do produto)
Hoje: `generate` lê só `requisitos/` → specs genéricos com `login()` do acesso 1 → explore **depois**, um usuário, sem 4xx → grep `@executavel` ignora `@rascunho`. Variantes de permissão e “o que o perfil vê” não entram na prova. Run geral e run focado deveriam ser o mesmo motor com recorte.

### Pipeline alvo

```
sync requisitos
ensureChromium
[1] mapa por perfil → scripts/falhas/MAPA-PERFIL.json
[2] join → scripts/falhas/ROTEIRO.json
[3] generate-agent (prompt: ROTEIRO + MAPA + requisitos)
[4] audit / massa existente / Playwright / triagem (Discord só PRODUTO de run real)
```

Se F5 tem um login e as US citam vários papéis: log claro + cobertura de permissão **não** marcada como feita.

### MAPA-PERFIL.json
Por label F5: menu, rotas do escopo, controles visível/ausente, empty/erro visível, lista `http[]` (method, url, status, codigo JSON se houver). Login via o mesmo espírito de `templates/workspace/helpers/auth.ts` (contexto após Entrar). Focado: só `labels` + `paths` do escopo. Geral: links de menu após contexto.

### ROTEIRO.json
Campos: `us`, `ca`, `perfil`, `onde`, `fazer`, `esperado` (`visivel` | `ausente` | `http-ok` | `http-recusa` | `sem-ui` | `massa`), `specHint`.

Join:
- CA cita perfil e existe label F5 → essa linha usa `loginAs`
- CA exige UI e o mapa não tem rota/controle → `sem-ui`
- CA autoriza ver dados e o mapa tem a superfície → esperado consulta real (`http-ok` e/ou lista/empty), **nunca** só heading
- CA recusa ação (ex. importar) → controle `ausente`, **sem** pular a consulta da mesma tela
- Menu visível + HTTP 401/403 na API daquela tela, com CA de consulta → caso que deve **falhar** se ainda ocorrer (produto); não marcar verde

### Generate
`src/prompt-generate.ts` + `templates/qa-e2e-requisitos/SKILL.md` (e cópia que `ensureWorkspace` publica):
- `test()` sai do ROTEIRO; requisitos = texto do Entao/RN
- `loginAs(page, label)` obrigatório na linha com perfil
- `@executavel` só com Entao observável

### Escopo
`scripts/escopo.json` ou env, exemplo: `{ "modo": "geral" | "focado", "labels": ["…"], "paths": ["/…"] }`. Focado corta mapa e roteiro; regras iguais.
